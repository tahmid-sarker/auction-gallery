# Auction Gallery (Wishlist Tracking)

- [**View Live**](https://tahmid-sarker.github.io/auction-gallery/)

Auction Gallery is a modern wishlist tracking web application for browsing and bidding on auction items. It provides a seamless and visually appealing experience for users to explore products and participate in auctions.

## Features
- Browse a curated list of auction items with images and details
- Add items to your cart for easy tracking
- Responsive design for desktop and mobile
- Clean and intuitive user interface
- Modular React component structure

## Run Locally

To run this project on your local machine:

- **Clone the repository:**

	```bash
	git clone https://github.com/tahmid-sarker/auction-gallery.git
	```

- **Navigate to the project directory:**

	```bash
	cd auction-gallery
	```

- **Install dependencies:**

	```bash
	npm install
	```

- **Start the development server:**

	```bash
	npm run dev
	```
